# Home Page

A personal home page for my websites, projects, and online presence.

## Overview
This project is a simple portfolio-style landing page built to showcase my work, links, and other projects in one central place.

## Features
- Clean and responsive landing page
- Project showcase area
- Personal links and contact section
- Lightweight front-end experience

## Tech Stack
- HTML
- CSS
- JavaScript

## Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Sarthak-Budhodkar/Home-page.git
   ```
2. Open the project folder.
3. Launch `index.html` in your browser, or serve it locally with:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser.
